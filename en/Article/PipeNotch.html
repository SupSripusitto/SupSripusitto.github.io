    • Cylindrical Pipe Notching without Notching Machine

    The pipe structure is one of the most cheapest structure. However, cylindrical pipes welding other than parallel angle needs to minimize the welding thickness (not accounted for repeating the welding) for maximum tensile stress. That is we need to cut the tip of the pipe to minimize void between each pipes. In the present, pipe notching is convinient by automatic notching machine which is cylindrical shaped sandpaper milling or controlled laser cutter. Also, both are expensive. Nevertheless, many DIY technician use rough DIY flat pattern. This activated my curiosity. Why don't we just make it as precise as possible and use it forever. Additionally, the DIY flat pattern has some limitations when angle is not the standard like 45° or 90° and some non-negligible error when pipe diameter is not the same. This drives me to create a unified tool which could create every possible flat pattern for every situation for pipe notching.

    First, we need to imagine how pipes are assembled in 3D. We'll see 2 cylinders intersecting at the parametric curve which is parametrized by angular coordinate. Then, we define XYZ cartesian coordinate and let R denotes the inclined cylinder's radius. Similarly, r denotes the vertical cylinder radius. For the analysis convinient, we define the UVW coordinate for inclined cylinder governing equation as below.

    We get two governing equations for each cylinders as $$ \begin{cases} x^2 + y^2 = r^2\\\\ u^2 + v^2 = R^2 \end{cases} $$ Observe that these two equations' coordinates are mismatch. Hence, we need to use the concept of linear transformation to find the relation between XYZ and UVW. Obviously, U and X are the same basis. Thus, we need to consider just YZ with UW which is simple trigonometry problems as below.
    $$ \begin{pmatrix} v\\w \end{pmatrix} = \begin{pmatrix} \cos \varphi & -\sin \varphi\\ \sin \varphi & \cos \varphi \end{pmatrix} \begin{pmatrix} y\\z \end{pmatrix} $$ Therefore, the transformed system is $$ \begin{cases} x^2 + y^2 = r^2\\\\ x^2 + (y\cos\varphi - z\sin\varphi)^2 = R^2 \end{cases} $$ Since we want to project the curve to flat pattern, it might be more convinient if we use polar coordinate. Luckily, the first equation is the same as polar transformation. Hence, we just transform XY with this criterion to the second equation with some manipulation to get the solution as below. $$ \begin{align*} (y\cos\varphi - z\sin\varphi)^2 &= R^2-x^2\\ y\cos\varphi - z\sin\varphi &= \pm\sqrt{R^2-x^2}\\ z\sin\varphi &= y\cos\varphi \pm\sqrt{R^2-x^2}\\ &= r\sin\theta\cos\varphi \pm\sqrt{R^2-r^2\cos^2\theta}\\\\ z &= r\cot\varphi\sin\theta \pm\csc\varphi\sqrt{R^2-r^2\cos^2\theta} \end{align*} $$ Though the analysis ended, there's an uncleared problem to solve. "How can we consider the plus-minus sign?". This leads us back to the equation which has only plus-minus sign term in RHS. This equation tell us that the plus-minus sign determine whether LHS is negative or positive. As z and sine are positive, the final plus-minus sign will be positive (plus-minus sign is swapped before the final step). That is the critical point is where y = 0 or the angular coordinate is at 0° or 180°. However, we can adjust some sinusoidal phase for convinient as I shift it for 90°. That is whether we scale the pipe size to any value in the same r/R, we still scale this pattern without needs to re-analyze. (Google Docs or Canvas could perform this perfectly.)
