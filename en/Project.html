    • Argon Molecular Simulation

    This project is my hobby for learning about fundamental of molecular simulation to predict some properties of the species. I always believe that the frontier knowledge can't be made without strong first principles understanding. Therefore, I started this project by considering ideal gas. In this step, I derived all equation of motions for every particles, boundary collision motions and temperature and pressure by statistical mechanics. This experiment verified the gas constant value by finding Boltzmann constant with the resulting about 99.98% of accuracy. Then, I developed real gas simulation using argon as reference data, since argon is a monoatomic gas. This step used Lennard-Jones atomic potential model; therefore, we need to rewrite integration method from Euler to Velocity Verlet Integration. Also, I added thermostat to control the system to be in NVT ensemble instead of NVE ensemble. I also thought that for larger scale might need GPU computing. However, in this case, 1000-10000 particles is enough in Monte-Carlo; hence, GPU programming is unnecessary since it will send data to VRAM instead of CPU with faster RAM.

    Skills : Python, NumPy, Matplotlib, PyTorch

    Acquired : Statistical Mechanics, Molecular Dynamics, Velocity Verlet Integration, GPU Programming

    Inverted Pendulum Control Simulation

    This is another hobby project for learning about unstable dynamical system which is hard to control. First, I analyzed the system using non-inertial frame mechanics to develop the model. Then, RK4 has been used to simulate instead of executable package, since the package is hard to track real time manipulated variables while controlling. Next, PID control loop was developed by controlling the external force exert to the pendulum base until it upright on the origin. Therefore, I need to use the cascaded PID instead of the single loop to control both pendulum angle and position with only one manipulated variable as external force. However, after some experiments for tuning by Ziegler-Nichols method, the pendulum still unstable. After trying linearize the model to find root locus, the pendulum still swing far from the setpoint. By trial & (mostly) error of tuning, I could stabilize the pendulum with some random gain and override control to trim pendulum angle setpoint from the outer loop as it could be controlled. Though the pendulum has been stabilized, it's stable at only small angle far from the upright position. Hence, I found that PID controller has a lot of limitation in low control robustness and extremely high control efforts.

    Skills : Python, NumPy, Matplotlib

    Acquired : Non-inertial frame mechanics, PID tuning, Root Locus, Controller performance

    Absorber McCabe-Thiele Simulation Package

    This project is inspired by the homework where I need to calculate the absorber stages by performing McCabe-Thiele between the micrometer area between graphs. The homework also activated my curiosity with a question "In the classroom we design it. In the real world we operate it. How can we determine the concentration while operating?" (Also, how to do this homework with human's eyes.). I realized that in the operation and design have some intersections, the conservation of mass and thermodynamics can't be violated. Therefore, I planned to develop Python package to calculate all of this instead of Aspen which is large, expensive, and black boxed. In this package, pinch point is automatically calculated. We can choose whether to put recovery or purity. Additionally, this package is powered by Newton's method to find the exact all composition which is analyzed by my graphical intuition. The resulting package is light-weight, fast, and precise to the machine epsilon without divergence problem (I tested in some extreme conditions).

    Skills : Python, NumPy, Matplotlib

    Acquired : Graphical Intuition for Separation Processes
